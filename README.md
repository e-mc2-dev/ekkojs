# EkkoJS

A JavaScript/TypeScript runtime built from a Rust host, V8, and a .NET 10 AOT native layer. ESM only.

- Author: hello@e-mc2.dev
- License: MIT
- Organization: E-mc2.dev

## Install

```sh
# macOS / Linux
curl -fsSL https://ekkojs.com/install.sh | sh
```
```powershell
# Windows (PowerShell)
irm https://ekkojs.com/install.ps1 | iex
```

EkkoJS is the result of the whole team's effort, enjoy using it!
